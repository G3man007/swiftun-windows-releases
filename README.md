# SwifTun для Windows

Официальные сборки приложения SwifTun для Windows. Здесь только готовые установщики, исходный код хранится отдельно.

**[Скачать последнюю версию](https://github.com/G3man007/swiftun-windows-releases/releases/latest)**

| Файл | Для каких компьютеров |
|---|---|
| `swiftun-windows-<версия>-x64-setup.exe` | Windows 10 (1809 и новее) и Windows 11, 64 бит. На ПК с ARM тоже работает, через эмуляцию x64 |

Установщику нужны права администратора: он ставит службу SwifTun Tunnel, через которую работает VPN. Установленное приложение само проверяет обновления здесь и предлагает их установить. Перед установкой оно сверяет SHA-256 файла, а у подписанных сборок ещё и подпись разработчика.

Если Windows показывает «Система Windows защитила ваш компьютер», нажмите «Подробнее», затем «Выполнить в любом случае». Так SmartScreen реагирует на новые программы, пока у них мало скачиваний.

Контрольные суммы лежат в `SHA256SUMS.txt` каждого релиза. Проверить файл: `certutil -hashfile <файл> SHA256`.

Политика конфиденциальности: https://www.swiftun.com/privacy/
